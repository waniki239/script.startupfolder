# Startup Folder

Startup Folder is a Kodi service add-on that automatically opens a configured favourite when Kodi starts.

## Features

- Opens a configured Kodi favourite automatically at startup
- Supports Kodi 21 (Omega)
- Lightweight and easy to configure

## Installation

Install from the waniki239 Kodi repository or download the latest release from GitHub.

## Configuration

1. Open the add-on settings.
2. Enter the name of a Kodi favourite.
3. Restart Kodi.

The configured favourite will be opened automatically after Kodi starts.

## Requirements

- Kodi 21 (Omega)
